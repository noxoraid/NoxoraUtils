# About NXR

## NXR

NXR is an open-source Geometry Dash mod menu developed by **Noxora** using the **Geode** modding ecosystem.

It provides a collection of gameplay utilities, botting/TAS tools, editor extensions, visual utilities, quality-of-life features, and experimental tools.

## Project Details

- **Name:** NXR
- **Mod ID:** `noxora.nxr`
- **Developer:** Noxora
- **Version:** v1.1.0
- **Game:** Geometry Dash
- **Mod Loader:** Geode
- **Language:** C++
- **Platforms:** Windows, macOS, Android
