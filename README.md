# Noxora

**Noxora** is a Geometry Dash mod focused on botting/TAS functionality, gameplay utilities, editor features, and various quality-of-life tools.

> **Note:** Noxora is currently under development and may contain bugs. While the mod includes many features, some features may not work perfectly in every situation.

# v1.1.1 — BIG UPDATE

This update introduces major improvements to the Noxora interface, botting system, macro system, and overall functionality.

### UI Improvements

- **Redesigned UI** — Updated the user interface for a cleaner and more organized experience.
- **Click Indicators** — Displays visual indicators showing when inputs are being registered.

### Botting & Macro Improvements

- **CBF Bypass** — Adds functionality related to bypassing CBF restrictions.
- **Record Without Restart** — Allows recording to begin without requiring a level restart.
- **Bot Speedhack** — Adds speed control functionality to the bot.
- **Export Macro to JSON** — Allows recorded macros to be exported in JSON format.
- **Merge Macros** — Combines multiple macros into a single macro.
- **Fixed Particle Issues** — Fixes problems related to particle behavior during botting or playback.
- **Random Fixed** — Adds additional functionality related to fixed/randomized behavior.
- **Ignore Input** — Allows selected inputs to be ignored during macro operation.
- **Always Save as JSON** — Macro data can now always be stored in JSON format.

### Macro Accuracy

> **Important:** Earlier versions of the macro system could produce inaccurate recordings or playback behavior and occasionally encounter bugs.

The macro system has been significantly improved in v1.1.1, providing **much higher playback accuracy and improved reliability**.
